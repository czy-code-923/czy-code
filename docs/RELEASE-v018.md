# 星枢 0.18

- 主机套餐可设 GB/GiB、双向 / 仅入站 / 仅出站 / 周期较大值、每月重置日、网卡选择与历史用量校准。Linux / Windows 使用实际 OS 计数，断报与计量缺口明确显示。
- 用户计费倍率与方向，Clash/Mihomo 用量头同步计费余额；默认双向 1×。
- 独立设备订阅、名额、用户组限制和设备节点权限；设备可编辑、停用、删除。标准协议不能识别复制凭据后的物理硬件，界面明确说明。
- 连接元数据分页浏览全部保留记录、时间 / 字节排序、滚动与可见区域 30 秒刷新；每轮最多 100 条，最多 7 天 / 20,000 条。
- API、OpenAPI、Telegram /hosts /traffic /users /devices、主机额度与设备名额通知同步更新。
- 修复自定义 API / 分享端口的原生 Web 代理；测试二进制内嵌历史模板，部署预检在空目录验证。

包含完整源码、Linux / Windows amd64 / arm64 二进制包、固定摘要安装器、Agent 发行包和专用宝塔升级包。内核固定官方 sing-box 1.14.4、Xray 26.10.21、FRP 0.71.1，后台仍可选择最新稳定版或指定版本。
