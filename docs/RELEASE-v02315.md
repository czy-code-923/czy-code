# 星枢 0.23.15

修正用户、用户组、订阅及其他业务表格的垂直对齐，保留所有协议、身份、权限、计量、客户端策略和订阅行为。

- 单元格中的名称、状态、流量和整组操作按钮统一垂直居中，仍保持标准 table-cell 布局，长名称 / 多行流量信息不会把其他列顶到顶部。
- 用户及订阅表格增加统一边框、圆角、轻量行底色和按钮悬停反馈，订阅状态使用统一标签。手机保留局部横向滚动和足够触控高度，兼容深浅主题。
- TUIC v5 原有支持保持：sing-box 服务端，QUIC / UDP + TLS，UUID + 密码，Mihomo / sing-box 订阅。节点配置明确展示“TUIC v5 · 已适配”，说明当前 TUIC 适配没有 Hysteria 的原生端口跳跃参数；协议能力 API 明确返回 port_hopping=false。
- 不修改已有入站参数、用户权限、订阅身份或流量计费，不更新现有内核版本。端口跳跃仍仅用于 Hysteria / HY2。

刷新浏览器以加载新版样式。控制面更新会短暂重启本机服务；使用同一版本发布包的校验、备份和失败回退机制。
