# 0.19 订阅动态更新与自动设备识别

主流程不变：主机 → 内核 / 协议 → 用户组授权 → 客户端策略 → 用户稳定订阅。

## 已有用户添加节点

用户订阅每次请求都从当前用户组计算节点，设备节点权限再取交集。修复后台订阅列表仍显示创建时快照的问题。给现有用户组加节点、用户换组、移除或删除节点，不需重建用户、不需重新生成订阅链接，UUID / 密码保持不变。

在线 Agent 正在应用新身份或新授权时，返回 503 + Retry-After:3，说明“稍后更新原链接”，不再用 200 让客户端缓存缺节点的成功配置。应用回执后，同一链接返回最新完整可用列表；停用 / 离线 / 失败的节点不伪装成运行成功。客户端需主动执行“更新订阅”或按自身定时更新周期拉取，控制面无法直接改写客户端已缓存的配置。

订阅响应使用 no-store、Vary: User-Agent, X-Hwid。分享前检查不注册设备、不改真实客户端 UA，设备限制开启时也可以复制用户通用链接。

## 自动设备识别与限制

使用用户原来的同一个订阅链接。支持 HWID 的客户端回传 X-Hwid（10～64 位字母、数字、连字符或等号），可另提供 X-Device-Os、X-Ver-Os、X-Device-Model。首次自动登记独立连接身份，后续相同用户 + 标识复用；不再要求管理员手动创建设备。后台显示自报系统 / 型号、订阅请求 UA、代理连接来源及用量，可以编辑节点权限、停用、删除。

自动设备只存按用户隔离的标识摘要，不回显原始 HWID 或摘要。来源 IP 来自真实代理连接，不用 IP 数量猜设备数。旧版手工设备链接仍兼容，默认界面不再提供手工登记入口。新身份需要等待 Agent 部署，第一次请求可能返回 503，稍后重试同一链接不会重复占名额。

用户和用户组的 max_devices 取最严格非零值；0 不强制限制。支持标识的请求仍可自动登记，便于查看独立用量；不带标识且未限制的旧客户端继续使用通用身份。开启限制后通用身份撤销，未回传有效标识返回 409 + X-Hwid-Not-Supported:true，超过名额返回 403 + X-Hwid-Max-Devices-Reached:true / X-Hwid-Limit:true，被停用标识返回 403，不会自动重建。错误正文给出原因；具体弹窗文案取决于客户端。

HWID 是客户端自报安装标识，不是可信硬件证明。用户自行修改标识或复制已下载连接凭据，服务端无法可靠判断物理设备；标准 VLESS / Trojan 等连接本身不携带硬件 ID。Clash Verge / Mihomo 普通请求通常没有稳定 HWID，因此严格设备限制开启时会明确拒绝，应关闭此限制或改用支持的客户端。SS / Snell 共享密码无法逐用户执行设备限制。

新增 Happ 与 v2RayTun 的节点订阅选项和 UA 识别。默认采用兼容协议 URI 列表，不声称包含 Mihomo 的交互策略组；需要完整规则可选择对应内核 JSON。新版 Xray REALITY 的 PQ 组合继续限制在已验证的 Xray JSON，避免生成已知不兼容 URI。Happ / v2RayTun 是否回传标识取决于客户端版本与设置。

规范来源：[Remnawave HWID](https://github.com/remnawave/panel/blob/main/docs/features/hwid-device-limit.md)、[v2RayTun 请求头](https://docs.v2raytun.com/overview/device-limit)、[Happ 配置及 HWID](https://github.com/HappDev/happ_su/blob/main/dev-docs/app-management.md)。不启用其他供应商统计服务，不上传用户标识到第三方统计平台。

## 策略与双栈端点

同一节点按行展示 IPv4 与 IPv6，支持全部、仅 IPv4、仅 IPv6、手选。动态筛选切手选时保留当前实际命中结果，再单独取消地址族；节点引用保存为 endpoint:<id>:ipv4 / ipv6。旧的 node:<id> 明确表示整节点全部地址，旧名称绑定编辑时转换为可见稳定引用。

修复勾选节点后默认首项变成 DIRECT、IPv4-mapped 地址误判、名称匹配扩大到无关节点，以及缺失 PROXY 的最终规则。精确协议 / 地址 / 端口或唯一稳定导出标签优先，重名拒绝自动扩大。动态 ALL 随已授权节点更新，手选保留固定选择。编辑中的节点清单每 30 秒刷新，保留草稿；导入仅基础 / DNS 时无需映射未使用节点。

## 网络层与卸载

SS 支持 TCP+UDP / 仅 TCP / 仅 UDP，独立于 TCP、WS、gRPC 等封装选择；入站、导出与端口预检一致，新设置要求 Agent 0.19。SOCKS5 UDP 关联修复。详见 [协议网络矩阵](PROTOCOLS-v019.md)。

README / INSTALL 已增加读取本机管理员令牌、预览卸载、执行卸载的 Linux / Windows 命令。默认卸载仅移除项目运行组件，保留私有配置、数据库卷与备份；--purge-data 才显式销毁。它不卸载 Docker、不删除其他站点、共享 Nginx / 证书或全局防火墙。移除主管理端前请先在面板退役其他主机的 Agent。

## 升级

控制面、前端、Agent 同升 0.19，迁移 024 保留现有用户、节点和订阅。专用宝塔升级器安装 uninstall.py 与 admin-token.py 到 /opt/harbor，快装版放在安装根目录。旧链接继续使用，无需全体用户重新注册。完整 API 定义见 [OpenAPI](openapi.json)，设备列表权限与读取凭据权限分开；连接元数据使用 access:read。
