# 星枢 0.23：客户端与网关

自动选择使用客户端 User-Agent；无法可靠识别时返回通用节点 URI。Hiddify 若自动导入不成功，手动选 Hiddify App 配置。NekoBox Android 输出 Clash Meta 节点 YAML；NekoBox 1.4 前可选单节点 URI 二维码。sing-box Android 使用独立完整配置；规则集下载出站跟随最终策略，所有出站引用先检查。客户端实现与版本有差异，内核校验并不代表每款 App 已实机通过。

用户独立计量需服务器以独立身份认证。新建或编辑节点可显式启用：sing-box Shadowsocks 2022 AES-128/256 多用户或 sing-box 1.14+ Snell 用户密钥。使用该功能的 Agent 需 0.23+，各客户端也需支持相应认证；Snell 独立身份目前仅输出至明确选择的 sing-box 1.14+。原有共享密钥仍为共享流量，不推断个人用量，切换模式会改变该节点凭据，需要客户端更新订阅。额度与其他节点分开核算。

订阅 API 需要 `subscriptions:links` 权限：`GET /subscriptions/{id}/share` 返回链接和二维码载荷；`/content?client=nekobox` 返回客户端正文；`/nodes` 返回兼容 URI 节点及 ID；`/qr?kind=node&node_id=...` 返回 PNG。内容和二维码含有可登录代理的私密凭据，交由可信服务保管。严格 HWID 模式的普通订阅需真实客户端注册后使用设备专属订阅；管理员预览不占设备名额。其他 CRUD 和权限见 [OpenAPI](openapi.json)。

反代由总管理端的 root 网关执行器和 Nginx 管理，支持公网 HTTP/HTTPS 上游或指定本机应用端口。公网域名解析结果必须全为公网地址，网关固定已校验 IP 并对 HTTPS 上游校验证书及 SNI；配置仅允许超时、请求大小、WebSocket、Host 参数，不能注入任意指令。页面可查看生效 Nginx 文本与流量。请求/响应字节按完成的 HTTP 请求累计，长连接结束后入账，不含 TLS、TCP 开销，约每分钟回报；不作为用户代理额度。证书和反代删除需网关确认后完成，证书被引用时先解除引用；不撤销外部证书或删除其他应用文件。

首次安装随机生成独立管理员令牌、数据库密码及主密钥；准备脚本只替换示例占位符，重复运行保留已有真实凭据。不要公开令牌或订阅链接。升级保留现有密钥，按原配置应用数据库迁移；自动备份控制程序、网页、网关脚本，失败回滚程序与脚本。数据库迁移为新增字段，数据库也须保留原有备份。
