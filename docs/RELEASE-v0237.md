# 星枢 0.23.7

- 新的用户订阅使用独立身份：UUID 协议使用独立 UUID，密码类协议使用独立密码。到期、撤销或删除后，在线 Agent 同步并重启相关托管内核以撤销该身份；控制面失联时 Agent 按原有超时机制停止托管内核。
- 旧订阅保留现有凭据，管理员可在订阅列表手动迁移。迁移后客户端须更新订阅。若同一用户还有有效旧订阅，其旧通用身份仍有效；最后一条旧通用订阅到期或迁移后才撤销。
- 兼容模式按订阅生成身份，严格 HWID 模式按订阅与设备生成身份。流量仍归属原用户；设备标识是客户端自报，不能防止凭据复制。未托管的 SS/Snell 共享密钥不能独立撤销，独立身份订阅会过滤这类入口；托管独立身份的 SS 2022 / Snell 可使用。
- 主机可暂停和恢复管理。暂停后保留心跳和流量回传，停止托管代理；新版 Agent 在下一次同步立即停止，旧 Agent 在控制超时后停止。离线 Agent 不能远程唤醒。
- 修正订阅名称编辑、Telegram 设备汇总和无限设备用户的访问记录上限。新增当前/最新正式版检查；**自动安装更新尚未实现**。
- 本版本涉及数据库迁移，请先备份数据库及私密配置，再使用适配本安装方式的升级工具。升级后验证主机在线、代理、订阅和流量，再对旧订阅逐一迁移。
