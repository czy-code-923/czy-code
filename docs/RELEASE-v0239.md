# 星枢 0.23.9

- 用户组授权的 SS / Snell 共享密钥节点会随用户订阅发布，无需重新创建用户或订阅。授权变更后，客户端更新同一订阅即可获取或移除节点；仅向支持对应协议的客户端输出，策略组自动匹配实际节点。
- 独立身份节点继续使用各订阅的独立凭据。共享密钥属于入口级凭据，用户/订阅到期、撤权、设备停用和流量超额只能阻止后续订阅获取，不能撤销已导入的共享密钥，也不能准确按用户或设备计量；需要轮换节点共享密钥或改用受支持的独立用户身份。
- 硬件标识限制只控制共享密钥的订阅发放，不能阻止已发出的密钥复制到其他设备；客户端标识由客户端自报。
- 控制面和本机 Agent 可通过后台版本页更新；其他主机 Agent 在本次修复中不需要升级。
