# 星枢 0.24.0 · 商业计费接口

增加独立购买面板 Starhub Portal 的原子权益接口：可计费用户组检查、协议白名单、永久订单幂等开通与续费、稳定的独立身份订阅、同步套餐到期、账户启停。

商业用户只会获取白名单中的独立身份节点，原始分享链接、二维码和所有客户端格式共用此校验；用户组后续加入共享密钥节点也不会泄漏。共享节点仍可用于原有自用用户，不改变原自用授权。

新增 commerce:read / commerce:write API 权限。购买面板还需要 users:read、devices:read、subscriptions:read、subscriptions:links、profiles:read；请使用专用受限 API 密钥，不传递管理员登录令牌。

权益与独立身份在同一个数据库事务写入；同一订单重试不重复续期。到期过滤作用于代理端身份下发，不只是订阅地址；续费保留稳定订阅，并保持原始月份日期，31 日经短月后回到后续月份 31 日。

包含 PostgreSQL 集成验证：重复订单、冲突重放、续费保留链接、实际 UUID 到期排除、共享组拒绝、已有商业链接过滤新增共享节点、原自用共享节点回归。

保持现有 GB / GiB / 自动单位、主机接入、代理协议、端口跳跃、流量和订阅等功能。本轮仅需升级控制面，原 Agent 可继续运行；新安装 Agent 随分发包使用 0.24.0 标识。
