# 星枢 0.25.0

增加购买面板按订单拆分旧合并权益的商业 API：在同一数据库事务内创建独立用户和订阅、按套餐比例分配转换为 GiB 后的剩余字节、保留原到期与重置日期、停用旧身份并撤销旧链接。迁移使用持久化幂等记录，重试不重复发放；节点或容量校验失败整笔回滚。普通商业开通接口保持兼容。

增加 `GET /api/v1/commerce/capacity`，返回已占用、剩余的独立代理身份数。当前上限保持 500，购买用户拥有多份独立订单时分别占用身份；该上限不代表同时在线人数或带宽承诺。

安全范围：迁移需要 `commerce:write`，容量需要 `commerce:read`。不更改已有主机、协议内核、防火墙及非商业自用账户。旧身份撤权需要 Agent 应用对应新配置；迁移结果与分配字节留有审计。
