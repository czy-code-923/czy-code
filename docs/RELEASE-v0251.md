# 星枢 0.25.1

新增受 commerce:write 权限保护的 `POST /api/v1/commerce/renewals`，购买面板核款后可延长原商业身份与原订阅的到期时间。

续费按订单 ID 幂等，重试不重复延长；绑定 external_id、user_id 和 subscription_id，在图锁内验证。已删除、停用的身份及已撤销的订阅拒绝续费，不创建替代身份或新链接。仅延长期限，保留用户权限、UUID、订阅令牌、额度、已用流量、倍率和重置日。未到期从原到期时间追加，已到期从当前时间追加。

包含真实 PostgreSQL 回归测试，验证稳定身份、令牌、计量字段、订单重放及删除后拒绝重建。其余部署、Agent、协议配置和订阅生成保持现有行为。
