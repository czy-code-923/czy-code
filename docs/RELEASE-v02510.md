# 星枢 0.25.10 · 主机 IP、发布节点与订阅同步

修复 VPS 换 IP 后主机保留旧地址、已有节点不跟随，以及编辑协议时隐藏的旧 `endpoint_addresses` 导致“所选发布 IP 不属于此主机”的问题。

- 主机增加“自动跟随 Agent IP / 固定手动地址”模式。自动模式保留仍在网卡上的原 IP；原 IP 消失后更新为同类型新 IP，不会把公网地址替换成 Docker / 私网地址。空心跳保留上次有效上报。
- IP 变化在同一事务内更新主机、代理节点的连接地址及所选发布 IP，递增配置版本，通知上游链式节点重新同步。重复心跳不会反复递增版本。
- 手动修改主机 IP 也会同步精确引用旧 IP 的代理节点。独立域名、其他自定义连接地址、SNI、证书和身份凭据保留。
- 编辑器显示当前主机未回报的旧发布 IP，可直接取消；选择同类型新 IP 会替换旧值。手动输入连接地址会清空发布 IP 选择，避免被旧值覆盖或错误拦截。批量添加采用相同逻辑。
- IPv4 / IPv6 按类型分别处理；多个候选 IP 无法唯一对应时保留原选择，由管理员明确指定。FRP 的证书与父子配置保持原有编辑流程，本版不自动重写 FRP 地址。

## 升级与旧配置

只需升级控制面即可使用同步修复，现有回报网卡地址的 Agent 可继续使用。已有主机地址与历史 Agent 上报匹配，或尚为 `outbound-agent` 时，迁移为自动模式；已有独立域名、NAT 地址或无法确认归属的地址保留手动模式。若升级前已经出现“主机旧 IP / 上报新 IP”不一致，请在编辑主机中选择自动模式并保存，或明确填写新 IP。

代理节点中已选择的发布 IP 随同类型地址同步；未选择发布 IP 时，仅连接地址精确引用原主机 IP 的节点自动跟随。独立域名仍应由 DNS 提供商维护解析。

## 客户端订阅

原订阅链接、授权、用户及设备身份保留。所有客户端格式读取更新后的同一节点数据；兼容性过滤和可选参数适配继续生效。客户端必须更新订阅才能拿到新地址，已经导入的旧配置不会被控制面远程推送替换。公网端口、运营商路由及 DNS 可达性仍需实际验证。

## 验证

包含主机新 IP 上报、双栈变化、空心跳、多 IP、固定手动地址、手动修改后的节点同步、原订阅身份保持、7 种客户端订阅，以及编辑器旧 IP 替换和手动地址保存回归。发布流程沿用后端、前端、Linux / Windows 原生转发、安装与更新回滚检查，全部通过后才将候选版本提升为稳定版。
