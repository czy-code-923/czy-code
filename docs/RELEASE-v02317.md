# 星枢 0.23.17

HY2 服务端和客户端带宽独立设置，修正同值下发导致方向和限速用途混淆的问题；单个与批量协议编辑入口统一。

- 新建 HY2 默认 BBR 自动估计；可选 Brutal 实测客户端上传 / 下载。服务端保留独立协商上限。旧节点默认保持原下发行为，配置更新不更换用户、订阅或协议身份。
- 补充客户端 HY2 BBR profile、TUIC UDP 转发 / 心跳、AnyTLS 空闲会话选项；SS、Snell、Hysteria v1 的专属字段也可在批量创建中设定。v1 不再默填 100 Mbps。
- 完整 Mihomo / sing-box 订阅同步客户端字段，URI 分享对不可靠携带的调优选项显示提示。API / OpenAPI 与文档同步；配置导入明确区分 HY2 服务端上限与客户端提示。
- Agent 入站工作不携带订阅专属字段；HY2 链路独立带宽兼容旧 Agent。需要新客户端参数的链式出站对旧入口明确报升级要求。
- 增加数据库持久化、稳定订阅刷新、方向映射、格式 / 单位转换、旧 Agent 和原生内核转发检查，保留全套既有安装、卸载、回退和网络安全验证。

完整说明见 [协议参数与性能设置](PROTOCOL-PERFORMANCE.md)。不承诺跑满商家标称带宽，不自动增大系统缓冲区、开启 0-RTT 或更改已有节点。

为兼容当前 sing-box / Mihomo 的实际认证协商，Brutal 手动模式要求上传和下载均为正值；自动模式两项均不下发。0.23.16 候选版本保持为预发布，不部署到线上。
