# 星枢 0.23.19

首页、用户额度和访问记录使用统一流量单位。默认 GB，在系统设置 → 显示与单位中可选 GB、GiB 或自动十进制换算；偏好保存到后台，电脑和手机共用。

- 首页总量、用户本期已用 / 剩余 / 累计、入口流量、设备与访问记录跟随设置，小额流量保留足够小数。
- 首页主机套餐表跟随每台主机的 GB / GiB 偏好，与主机卡片一致。
- 用户配额编辑可切换 GB / GiB，换算保留原始字节，单独修改名称、权限或单位不会损失精度或重算账单；自动显示模式下默认用 GB 输入。
- 修复主机和用户的单位换算小数被浏览器步长校验拦截的问题。
- Telegram /traffic、/users 跟随全局单位；/hosts 跟随每台主机的单位。
- API 新增 GET/PUT /api/v1/display-settings，分别需要 site:read / site:write；公开 branding 只额外提供非敏感的显示偏好。所有计量、额度与订阅用量头继续使用原始字节。
- 数据库迁移只添加显示偏好，不修改流量、配额、到期时间或身份。现有 Agent 无需重装或升级。
