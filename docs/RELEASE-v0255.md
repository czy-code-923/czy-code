# 星枢 0.25.5

修复 Linux 一键新装只安装控制面和更新服务、导致域名 / 证书一直等待签发的问题。

- Linux systemd 新装自动补齐缺失的 Nginx、Certbot、Cloudflare DNS 插件和受控签发 / 域名 / 反代助手；已有宝塔和系统 Nginx 保留。
- 已安装面板可单独执行固定正式版的网关修复命令，复用原令牌、数据库与代理身份，兼容 0.25.x 控制面。
- 签发与域名应用串行处理；主站和订阅域名 HTTP 验证先准备 challenge，Cloudflare 签发不竞争 HTTP-01。未绑定域名时保留原生 IP:端口入口。
- 域名入口跟随实际原生网页端口（新装通常为 18080，兼容旧版 5173），并允许后台已支持大小的策略导入请求。
- 证书页显示助手心跳、Certbot 与 Cloudflare 插件状态，并提供修复文档入口。
- 后台升级会同步网关助手文件并暂停平台自己的 worker；卸载会停止其 service/timer。
- 增加依赖识别、已有站点保护、修复回滚、旧 API 兼容和正式发布前的真实 Linux Nginx / 本地证书端到端验证。测试使用假 ACME / DNS 和本地测试 CA，不向真实 CA 或 Cloudflare 申请证书。

安装修复步骤见 [域名与网关修复](GATEWAY.md)。
