# MVP 后续路线图

v0.3 另外完成防火墙策略/受限本地应用工具、UI主题与资源优化，详细交付边界见 FEATURES.md；真实 Linux 防火墙应用、Docker 和 systemd 运行本次未验证。

v0.2 已补齐基础逻辑修复及下一阶段的本地部分：类型化清单、原生配置预览、固定程序 check/verify 校验、私有版本暂存、历史成功版本回退、独立租约回收/续期。下列“阶段 1”的真实服务启动、远程设备身份及生产运维部分仍未完成，不能将本地暂存当作 VPS 发布。具体边界见 STAGING.md。

## 本版验收

- Compose 启动数据库、API、前端；宿主机只监听回环。
- 登记主机、节点、实例及 FRP 隧道；跨资源引用和主机端口冲突得到明确错误。
- 配置版本不可变，任务固定引用实例对应版本；重复请求返回同一个任务。
- 模拟 Agent 只领取自身主机任务；完成回报更新 `simulated` 并写审计。
- 同节点多主机、同主机多节点可表示；中转链可规划，不声称已生效。

## 阶段 1：单台测试 VPS 的真实受限执行器

1. Agent 一次性登记、设备身份/mTLS、吊销与重新登记；API TLS 网关、请求限速、私网/VPN 运维入口。
2. 固定版本且校验签名/摘要的 sing-box 与 FRP 二进制；制品来源允许列表，无任意 URL。
3. Go 类型化引擎适配器：生成原生配置 → 固定引擎校验入口 → 预检端口 → 原子配置替换 → 固定 systemd 服务重载 → 健康探测；禁用任意命令及扩展钩子。
4. 服务以独立低权限账号运行，特权 helper 严格限制到预定义服务动作；不暴露公网管理口；入站代理须显式认证、TLS、协议及客户端配置。
5. 统一主机端口预留表覆盖实例和 FRP remote_port，支持明确的 server/client 所属主机；不自动开放防火墙。
6. 失败自动回滚上个成功版本、人工回滚 API、阶段日志、差异预览、漂移检测；Agent 重启后的对账与配置摘要幂等。
7. 独立任务回收器、指数退避、死信/人工重试、取消语义、长任务续租、设备/控制面离线处理。

验收：只在获授权的测试 VPS 执行；验证失败配置回滚、重启恢复、旧租约防护、端口冲突、不误报运行状态。

## 阶段 2：代理 / FRP / 路由完整化

- sing-box 协议能力与版本兼容矩阵，显式支持的协议/TLS模板；安全凭据托管、客户端配置/订阅、订阅链接吊销。
- FRP 服务端与客户端角色建模、设备及本地目标授权、认证/TLS、TCP/UDP/HTTP(S) 路由、域名/证书；全局端口分配。
- route_hops 关系表、DAG 检查、跨主机出口链、路由规则/域名/IP集、DNS与防泄漏策略；先生成变更预览，分阶段发布。
- CRUD、分页检索、资源标签/分组、批量发布、实时日志、流量/延迟/可用性监测、告警与用量留存。

## 阶段 3：对外自助

- OIDC / MFA、用户/组织/成员、角色权限、API token 作用域与过期、逐资源授权；服务端租户解析、复合外键、RLS 与跨租户负向测试。
- 独立用户前台与管理前台复用稳定 OpenAPI；套餐、配额、并发/带宽限制、端口和域名租约、资源归属迁移、暂停/回收。
- 计费及订单按真实需求增补；支付幂等、用量结算对账、滥用处理与数据保留。
- 数据库备份恢复演练、审计外部存档、密钥轮换、可观测性、SLO与事故响应。

## 阶段 4：扩展

- Xray 适配器，沿用主机/实例/任务/配置接口；先做能力协商及兼容测试。
- 业务量需要时再引入专用任务队列和拆分服务；当前保留模块化单体，避免过早微服务化。
