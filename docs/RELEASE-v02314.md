# 星枢 0.23.14

修复桌面用户权限与订阅分享页面的表格错位，并增加可选的 Hysteria / HY2 UDP 端口跳跃，保留已有协议、计量、用户、策略、API 和订阅身份。

- 操作按钮移入单元格内部容器，避免 Flex 破坏表格列和行高。长用户 / 订阅名、用量和权限正确换行；桌面固定列宽，手机局部横向滚动。分享用户、格式、链接、二维码分区统一表单样式，说明折叠，保留全部操作和明暗主题。
- 单节点新建 / 编辑、批量协议及手动 JSON 增加 `hop_ports`、`hop_interval_seconds`。仅 Hysteria / HY2 显示；API 严格检查协议、内核、Linux Agent 版本、公开监听、保留端口、间隔及有界范围。
- 创建 / 编辑 / 批量部署预留全部端口并检测冲突，Agent 检查本机端口；订阅按 Mihomo / sing-box 输出各自原生字段，不混用端口范围语法。原业务端口继续支持纯 URI 客户端回退。
- Agent 保持低权限；同版本正式包提供本机受限助手，专有 nft NAT 表、逐层禁止符号链接、类型封闭请求、原子检查与应用、45 秒失联清理。停用 / 删除 / 暂停 / 卸载覆盖对应转发。需在目标主机显式执行助手安装命令，不默认启用现有节点的跳跃。
- 连接修复 / 更新命令兼容标准 Linux Agent 和原管理机布局；保留内核及身份。OpenAPI、协议能力目录和安装分发同步更新。
- 更新仅测试工具的间接 glob / minimatch 依赖，修复 npm 报告的已知漏洞；保持现有 Vue / Vite 与生产依赖，重跑测试和构建。

升级：控制面「系统设置 → 后台版本」更新后强制刷新页面。远端 Agent 按主机页面命令升级，端口跳跃额外需要目标 Linux 上 nftables 和本机助手，云安全组 / 系统防火墙按实际入口放行。未启用跳跃的旧节点保持原配置。管理更新可能短暂重启管理机托管的内核。

完整使用、权限边界、平台限制与客户端最低版本见 [PORT-HOPPING.md](PORT-HOPPING.md)。源代码、四平台发行包及校验摘要由发布工作流重新构建；真实 VPS 更新结果另行核验。
