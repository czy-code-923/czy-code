# 星枢 0.23.18

主机流量单位跟随每台主机的设置，不再统一显示为 GiB。

- 编辑主机或主机流量时选择 GB / GiB，并保存该偏好；刷新和重新打开后保持选择。
- 主机卡片的已用、剩余、额度，以及流量详情中的周期 RX/TX，都使用选定单位，不再自动切换到 TiB。
- 套餐校准输入跟随已保存的单位，避免 GB / GiB 混淆。实时速率保留按量级显示。
- GB = 1,000,000,000 字节；GiB = 1,073,741,824 字节。切换单位保留额度的原始字节，不重置流量、不改变周期或计费方向。
- API 增加可选 display_unit（GB / GiB）。旧 API 请求省略该字段时保留原设置；迁移中的旧主机保留 GiB 默认值。
- 新增数据库迁移和持久化、计费不变、旧 API 兼容、主机显示及校准换算回归验证。

本次只需更新控制面，现有 Agent 无需重装或升级；协议、节点凭据和订阅保持不变。
