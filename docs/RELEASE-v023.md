# 星枢 0.23.0

- 修正 sing-box 规则集下载使用不存在的出站；为 Android 选择兼容模板，NekoBox 支持节点 YAML、URI 和单节点二维码，Hiddify 保留专属配置。
- 订阅链接、完整正文、节点列表与二维码可由独立 API 权限获取；管理员检查不消耗设备名额。
- 新增可选 SS 2022 AES / Snell 独立用户身份和流量计量，原共享入口保留；支持的客户端和 Agent 版本见工作流。
- 已签发证书可编辑和删除；反代支持受校验公网 HTTP/HTTPS 上游、手动参数、Nginx 生效配置与独立流量计数。
- 加固示例令牌处理，新安装生成不同随机令牌，升级保留现有凭据。

兼容范围与限制见 [WORKFLOW-v023.md](WORKFLOW-v023.md)。原生配置测试不等同所有 Android 客户端的实际导入测试。
