# 0.10 后续路线

已交付的功能以 FEATURES.md 为准，早期版本的规划和验收文档保留用于追溯。

1. 安全与可靠性：管理员 MFA / OIDC、作用域令牌、设备 mTLS、密钥轮换、生产数据库恢复演练、持续依赖扫描。
2. 计量：停机 / 断网 / 高连接数压测、缩小计量误差、并发 / 速率限制、按设备会话、共享密钥协议更可靠的身份方案。未经验证不承诺计费级准确性。
3. 协议与网络：更多 FRP 类型、明确支持版本的更多客户端、SS / Snell 用户能力、真实 CGNAT / IPv6 跨机验收、分阶段健康回滚。
4. 运维：告警、批量变更影响、保留策略可配置、主机 / 用户搜索分页、Windows 防火墙和可选云安全组适配。
5. 对外自助：组织 / 成员 / RBAC、服务端租户解析与隔离测试、独立用户前台、套餐与支付。必须先解决隔离与计量可靠性。
