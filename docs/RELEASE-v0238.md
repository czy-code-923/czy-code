# 星枢 0.23.8

- 系统设置 → 后台版本：显示当前版本、检查 GitHub 最新正式版，管理员确认后可自动更新支持的 Linux systemd 安装。Windows、Compose 和未安装更新助手的环境继续使用对应的手动升级方式，页面明确显示可用状态。
- 更新助手仅连接回环地址，通过固定官方仓库获取对应架构的正式安装包，核对 GitHub SHA-256 和大小，拒绝任意 URL、路径、命令与降级。委派 API 密钥不能提交更新或访问本地工作接口。
- 更新前检查磁盘空间并备份文件；停止控制服务写入后备份 PostgreSQL。替换后验证实际 API 版本，失败时恢复数据库、文件及原服务。独立 systemd 定时器和私密日志用于恢复中断的任务。更新期间托管节点可能短暂中断。
- 更新数据库和文件备份保留于 `/var/lib/starhub-updater/<安装布局>/<任务 ID>/`，包含私密数据，仅 root 可读。不要将该目录上传或公开；可在确认运行正常后按自己的备份策略归档。自动更新不切换代理内核、宝塔 Nginx 或远端 Agent 版本。
- 安装包附带 `scripts/install-panel-updater.py`：Linux 新安装自动注册助手；现有 `/opt/harbor` 升级包注册助手。其他受支持的 Linux 安装可执行 `sudo python3 scripts/install-panel-updater.py --env /实际路径/starhub-control/control.env`。助手要求安装目录由 root 持有且其他用户不可写，环境文件权限为 `0600`。
- 保留 0.23.7 的独立订阅身份、订阅名称编辑、主机暂停/恢复、客户端访问记录与 Telegram 设备汇总修正。新订阅立即使用独立 UUID/密码；旧订阅仍由管理员手动迁移并通知客户端刷新。到期身份从托管代理配置中撤销，不只使下载链接过期。

验证包含数据库支持的 Go 测试、前端测试/构建、更新包校验和中断恢复测试，以及隔离 Linux 环境中真正替换控制端二进制、备份与故障恢复数据库的集成测试。线上部署结果应另行核实。
