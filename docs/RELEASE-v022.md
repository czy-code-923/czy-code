# 星枢 0.22.0

- 修正 App 与内核格式混用：v2rayNG/v2rayN/NekoBox 改为节点订阅，Hiddify 保守筛选；sing-box App 补齐 TUN 和节点选择接口。
- 按客户端过滤节点后重新编译策略组、规则、DNS；去掉递归空组，丢失的规则目标拒绝连接，检查显示端点数量。
- 用户权限页面自动刷新个人用量，显示独立计量覆盖范围和共享入口总量；共享流量不冒记为个人账单。
- 本地二维码分享；一键查询面板地址、默认 30 分钟的 IP 备用入口及关闭命令，保留显式常开与 SSH 转发。
- 源码、四平台包、Linux/Windows 自动准备环境的一键安装、卸载和令牌工具同步更新。

验证范围与协议边界见 [WORKFLOW-v022.md](WORKFLOW-v022.md)。客户端版本可能不同，内核配置校验不等于每款手机 App 的实际测试。
