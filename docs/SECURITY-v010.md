## 功能安全检查

管理 API 采用现有管理员令牌、Agent 令牌只允许本机作用域；计量主体必须预先由本机配置授权。绝对计数器绑定主机 / 内核 / 主体，拒绝负数、超大数字、身份变更、URL / 路径 / 查询串目标。批次最大 512 KiB / 2,000 计数器 / 100 事件。配额字段允许修改额度，不允许客户端提交用量余额。

凭据 AES-GCM 托管、预览脱敏；订阅与管理路由分离，公开订阅不提供访问记录。内核统计端口只监听 127.0.0.1，sing-box 使用本机随机密钥，Xray 只启用 StatsService。没有新增公网管理端口、任意 shell / 任意原生配置输入。

测试覆盖跨机授权、过期 / 撤销订阅、未知字段、版本停止确认、删除保护、配额重试与重置、IPv6 连接记录、实际内核转发计量和安装失败回滚。一次性接入包附完整修复版源码和 GPL 许可，可按源码回执重建校验。

## 仍需完善
