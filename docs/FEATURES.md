# 0.12 功能核对

|模块|已实现|边界|
|---|---|---|
|主机与接入|主机 CRUD、吊销、一次性 Agent 命令、每机内核能力与状态|Linux systemd 一键安装；Windows 独立安装脚本；其他真实 VPS 需执行接入命令|
|内核与协议|sing-box / Xray，8 种结构化协议模板，必填与可选项，编辑 / 删除 / 启停|协议与客户端兼容矩阵按版本限制，不承诺所有原生协议|
|用户 / 用户组|独立凭据、到期、授权、删除撤销、轮换|单管理员；没有商业租户隔离|
|流量 / 配额|真实内核计量、已用 / 剩余 / 分配 / 累计、重置 / 超额撤销|6 种独立用户协议；SS / Snell 只按入口；短时超额与计量误差|
|访问元数据|来源 IPv4 / IPv6、目标域名 / IP、端口、用户筛选|有界记录，非完整浏览历史；不解密 HTTPS|
|订阅|14 个客户端选项、5 类基础格式、模板、编辑 / 删除 / 复制 / 轮换，额度头|具体能力不匹配拒绝导出；Xray REALITY 目前只验证 Xray 客户端|
|域名 / HTTPS|可选主站域名、IP:端口、独立订阅域名、网关回报、ACME、证书续期、反代|DNS / 可达性仍由实际网络决定|
|穿透 / 链路|FRP TCP、客户端独立主机、IPv6、本地目标、至多 8 跳 / 防环|未实测所有公网 NAT / CGNAT 拓扑；FRP UDP / HTTP 等仍待做|
|防火墙|版本策略、预览、SSH 保护、受限 root 应用及超时回滚|不自动接管 Windows 或云安全组|
|安全 / 资源|SHA 校验、密钥加密、回环管理端口、无任意 shell、单内核合并进程、有界记录|完整安全审计 / 压测仍待做；安全扫描不证明无漏洞|
|UI / 清理|五步导航（权限后增加客户端策略）、主页、明暗主题、移动布局、受保护 Acceptance 清理|原运行配置保留，旧文档是历史记录|

客户端策略与双栈、指定重置日和受控 Linux 卸载详见 [0.12 工作流](WORKFLOW-v012.md)。新总管理端一键部署命令在 README；Windows / 非 systemd 的限制在 INSTALL.md。
